# Sample USD for sandbox publish

Use this file when you do not have a local KB3D library path configured:

`projects/production_hub/samples/sample_assembly.usda`

In **Production Hub → Build**, set **USD output** to the absolute path of this file (or browse to it), then **Publish** against your sandbox ftrack task.

The prim carries `kb3d_asset_code` custom data so Iconik metadata inference matches KB3D-style naming in demos.
